# Угадай число

Небольшая браузерная игра без сторонних библиотек. Компьютер загадывает случайное целое число от 1 до 100, а игрок пытается его угадать.

## Возможности

- Проверка введённого числа и подсказка, больше оно или меньше загаданного.
- Подсчёт попыток.
- Проверка допустимого диапазона от 1 до 100.
- Кнопка для начала новой игры.
- Адаптивный аккуратный интерфейс.

## Запуск

1. Скачайте или клонируйте проект.
2. Откройте файл `index.html` в любом современном браузере.
3. Введите число от 1 до 100 и нажмите **«Проверить»**.

Сервер и установка зависимостей не требуются.
